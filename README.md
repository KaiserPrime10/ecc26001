# ecc26001

A multilingual, voice-first AI assistant that helps citizens fill government forms in their own language.

Built for ECCLISIA 4.0 by Team MATU.

# Problem

Most government portals are English-first and assume users can read official terminology and type long forms. Rural and regional-language citizens often face:

Language barriers
Low digital literacy and limited typing skills
Difficulty understanding official terms
Poor internet connectivity
Dependence on middlemen, which adds cost and errors

# Solution

Awaz is an AI assistant that sits on top of a form and helps the user:

Translate form fields and instructions into their regional language
Speak answers instead of typing (voice-to-form)
Scan ID cards and certificates to auto-fill fields (OCR)
Get guided step by step by a chatbot that explains each field
Validate entries and catch errors before submission

The assistant is built as a standalone component so that, in the future, it can be dropped into any portal as an embeddable widget
